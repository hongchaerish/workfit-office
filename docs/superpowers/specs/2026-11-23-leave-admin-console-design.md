# 근태·휴가 — 조회는 업무 화면, 관리는 관리자 콘솔 (2026-11-23)

## 결정
- 상용 그룹웨어처럼 **현황 조회는 업무 화면**(근태·휴가 메뉴, 권한별 범위: 임원·인사 전사 / 부서장 부서), **설정·조정은 관리자 콘솔**.
- 임원은 콘솔에 들이지 않는다 — 업무 화면에서 전사 근태·휴가·연차 현황을 본다.

## 권한
- 새 관리자 권한 짝 `admin.leave.view` / `admin.leave.manage` (영역 '관리자 · 근태·휴가', 콘솔 접속 포함).
  - view: 콘솔의 연차 관리·근무 정책 화면을 본다. manage: 연차 수동 가감·근무 정책 수정.
- 옛 권한(`S_GW_COMMUTE_ADMIN` 수정)에서 자동으로 이어받지 않는다 — 옛 기본값상 임원도 갖고 있어 콘솔에 들어오게 되므로. 운영 옮길 때 인사 역할에 넣는다(최고 관리자는 자동).
- '인사 관리자' 역할 서식에 `admin.leave.manage` 추가.
- 업무 화면 조회는 그대로 `commute.view`(범위)·전사 연차 원장은 기존 판정(`canLedger`).

## 메뉴 (관리자 콘솔 › 근태·휴가)
| 화면 | 주소 | 내용 |
|---|---|---|
| 연차 관리 | `/base/leave` | 전사 연차 원장(요약·표) + 수동 가감 + 직원 상세(연차 기간별 발생·조정·사용·소멸, 사용 내역, 조정 내역) |
| 근무 정책 | `/base/commute-policy` | 출퇴근·휴게·지각 유예 보기, 수정(기존 정책 창 재사용) |

## 업무 화면 변경
- 근태·휴가 › 관리 › 전사 연차 원장: **보기 전용**(조정 단추·조정 창 제거). 행을 누르면 직원 상세(보기 전용).
- 근태 화면 위 근무 정책 단추 제거(콘솔로 이동).
- 내 근태·휴가: 지난 연차 기간 요약 한 줄(기간·발생·사용·소멸).

## 지난 연차 기간 계산
- `calculatePastLeaveYears`: 지금 기간 전의 연차 기간마다 기간 마지막 날을 기준일로 `calculateUserLeaveBalance` 를 다시 돌린다(같은 계산, 숫자 어긋남 없음).
- 소멸 = 그 기간 끝의 잔여(0 미만이면 0).
- 시스템에 휴가 기록이 생기기 전 기간은 빼고 보여 준다(기록이 없어 전부 소멸로 보이는 일 방지) — 휴가 문서 중 가장 이른 시작일 이전에 끝난 기간은 제외.

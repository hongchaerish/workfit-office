# 업무계획 화면 개편 — 화면 설계서

- 작성: 2026-11-18
- 시안(직접 눌러 보는 파일): [2026-11-18-workplan-view-prototype.html](2026-11-18-workplan-view-prototype.html) — 브라우저로 열고 아래 **② 팀 업무**를 본다(① 현황판은 비교용으로 남겨 둔 탈락안).

## 1. 왜 바꾸나

- 지금 화면은 일정마다 굵은 글씨·테두리·그림자·색 바탕이 다 들어가 **눈이 피로하다**.
- 직원 한 명 줄이 비어 있어도 약 150px라 한 화면에 3~4명만 보인다. **직원이 늘면 전체를 볼 수 없다**.
- 요청자가 무엇을 보려는지 분명하지 않아 쓰임새별 세 안(부재 현황 / 팀 업무 공유 / 내 계획 짜기)을 그렸고, 사용자가 **② 팀 업무 공유**를 골랐다. 목적: "이번 주 우리 팀이 무엇을 하는지" 훑어보고, 필요하면 그 사람의 그날을 자세히 보고, 연락·회의로 이어 가기.

## 2. 목표 / 하지 않을 것 / 실패로 볼 것

**목표**
- 조용한 표: 일정은 글 한 줄, 종류는 왼쪽 얇은 선 색으로만.
- 많은 인원: 부서별로 접고, 내 부서만 펼친 채 시작.
- 칸을 누르면 그 사람의 그날 상세(칸 옆 작은 창). 내 일정이면 바로 고치고, 남의 일정이면 연락·회의로 이어진다.
- 일정 창(지금 쓰는 창)을 같은 구조로 고도화.
- 사람 순서는 **부서 관리에서 정한 부서 순서**를 따르고, 업무계획의 수동 "정렬 순서"는 없앤다.

**하지 않을 것**
- 휴대폰 화면(PWA 업무계획, `MobileWorkPlanEventSheet`) 개편 — 이번 범위 아님.
- 월간·내 주간 보기의 **구조** 변경 — 일정 한 줄 모양(C 모양)만 같이 바뀐다.
- 온라인(화상) 회의 주소 만들기 — 시안에 자리만 있음. 이번에는 넣지 않는다(4-4 참고).

**실패로 볼 것**
- 칸에 색 바탕·굵은 글씨가 다시 생겨 산만해지는 것.
- 마우스를 올렸을 때 **세로 열 전체가 칠해지는 것**(사용자가 뺀 효과).
- 스크롤하면 상세 창이 사라지는 것.
- 태그 버튼이 줄줄이 늘어서는 것(사용자가 뺀 모양).

## 3. 고려한 방법

| 안 | 내용 | 결과 |
|---|---|---|
| ① 현황판 | 칸에 휴가·외근 표시와 일정 건수만, 위에 오늘 인원 요약 | 탈락. 내용을 보려면 매번 눌러야 함 |
| **② 팀 업무** | 부서별 접기 + 칸에 일정 줄 글 3줄까지 | **채택** |
| ③ 내 계획 짜기 | 내 한 주 + 팀 빈 시간 | 탈락. 대신 ③의 "빈 시간" 생각을 상세 창·일정 창에 녹임 |

일정 모양은 A(지금) / B(가볍게, 색 점) / C(줄 글, 왼쪽 선) 중 **C** 채택.

## 4. 화면

### 4-1. 주간 표(② 팀 업무)

```
[‹][이번 주][›] 2026년 11월 3주차 11.16–11.22          [전체 부서▾][이름 검색][주간|월간|내 주간]
[▏업무][▏회의][▏외근·출장][▏휴가]                                   [모두 펼치기][모두 접기]
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬────┐
│부서·직원  │16 (월)   │17 (화)   │18 (수)·오늘│19 (목)  │20 (금)   │토·일│
├──────────┴──────────┴──────────┴──────────┴──────────┴──────────┴────┤
│▾ 개발팀 7명  휴가 1  외근·출장 1  미작성 1                                │
├──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬────┤
│홍채원     │▏09:00 팀장 회의│        │▏14:00 코드 리뷰│ ...                 │
│팀장 [나]  │▏11:00 API 설계 │        │                │                     │
│          │+1건 더   │          │          │          │          │    │
│정우성 …   │ (한 줄 걸러 아주 옅은 회색 바탕)                             │
│▸ 영업팀 8명  휴가 1  외근·출장 2  미작성 1   (접힘)                       │
```

- **일정 한 줄(C 모양)**: 보통 굵기 11.5px. 앞에 시각(옅은 회색, 숫자 폭 고정). 왼쪽 2px 선 색만 다르다 — 업무 `#d6dbe3`, 회의 `#b6a2f2`, 외근·출장 `#8cc8ee`(글자 `#155f8d`), 휴가 `#e3d36a`(글자 `#6f630f`). 상자·테두리·그림자·배경 없음. 종일 일정은 시각 자리에 "종일", 반차는 "오전/오후".
- **칸**: 3줄까지만, 넘치면 "+N건 더"(누르면 그 칸만 펼침, "접기"로 되돌림). 줄 높이는 내용만큼(빈 줄은 낮다).
- **주말**: "토·일" 좁은 한 칸(54px)으로 합친다.
- **오늘 열**: 아주 옅은 파랑 바탕, 머리에 "· 오늘".
- **날짜 머리**: 아래로 스크롤해도 위에 붙어 있다.
- **부서 줄**: `▾/▸ 부서명 N명` + 오늘 기준 `휴가 n`(노랑 글자) · `외근·출장 n`(하늘 글자) · `미작성 n`(주황 글자). 0이면 그 항목은 안 보인다. **오늘 업무 건수는 넣지 않는다**(사용자 결정). 누르면 펼침/접힘.
- **처음 상태**: 내 부서만 펼침. 부서 필터를 고르거나 이름을 검색하면 해당 부서가 자동으로 펼쳐진다.
- **종류 거르기**: 업무·회의·외근·출장·휴가 버튼으로 켜고 끈다(꺼진 것은 흐리게+취소선). 칸에서 해당 종류만 숨긴다.
- **미작성**: 사람마다 붙이던 '미작성' 배지는 없앤다. 부서 줄 숫자와, 그 사람 줄의 "이번 주 계획 없음"(옅은 회색, 5칸 합침)으로만.
- **사원 구분**: 사람 사이 줄 `#e4e8ee`, 한 줄 걸러 `#f8f9fb` 바탕, 이름(굵지 않게)과 직급을 두 줄로, 내 줄에는 `나` 표시.
- **마우스 올림**: 그 사람 **가로줄만** 옅은 파랑 + 이름 왼쪽 파란 막대 + 이름 파란 굵은 글씨, 올린 칸에 옅은 테두리, 마우스 옆에 `강민재 과장 · 18일 (수) · 3건` 안내. **세로 열은 칠하지 않는다.** 상세 창이 떠 있으면 안내는 숨긴다.
- **내 줄 빈 칸**: 마우스를 올리면 "+ 일정 적기"가 옅게 보인다.
- **없애는 것**: "↕ 정렬 순서" 버튼과 그 창(`RosterOrderModal`) — 4-5 참고.

### 4-2. 칸 옆 상세 창(그 사람의 그날)

칸을 누르면 칸 오른쪽(자리가 없으면 왼쪽)에 폭 360px 창이 붙는다. 누른 칸은 파란 2px 테두리. **문서에 붙어 있어 스크롤해도 칸과 함께 움직이고 닫히지 않는다.** 빈 곳 클릭·Esc·✕로 닫힌다. 다른 칸을 누르면 그 칸으로 바뀐다. 이름을 누르면 오른쪽 서랍에 그 사람의 한 주.

공통 구성:
- 머리: 이름 끝 두 글자 동그라미, 이름·직급, 그날 상태 표시(사무실 / 연차·반차 / 외근 / 출장), 아래 줄 `부서 · 11월 18일 (수) 오늘 · 3건`.
- 하루 막대: 9~18시 한 줄, 일정 시간대를 종류 색으로 칠함.
- 일정 목록: 왼쪽 `시작 ~ 끝`, 오른쪽 제목 / `종류 · 태그 · 참석 ○○` / 메모(옅은 바탕 상자).

**내 일정일 때 — "고치려고 누른다"**
- 머리 이름 자리에 "내 일정".
- 일정에 마우스를 올리면 `수정` `삭제`. 수정은 일정 창(4-3)을 연다. 삭제는 바로 지우고 4초 동안 "되돌리기" 알림(확인 창 없음).
- 휴가에는 버튼 대신 "휴가는 휴가원으로만 바꿀 수 있어요".
- 목록 아래 점선 버튼 "+ 이날 일정 추가"(비었으면 "이날 일정 적기").
- 바닥: `‹ 전날` `다음날 ›` … `내 한 주`.

**남의 일정일 때 — "같이 일하려고 누른다"**
- 고치기 버튼 없음.
- **오늘이면 맨 위 '지금' 한 줄**: "지금은 비어 있어요 · 다음 일정 12:30 오후반차" / "지금 주간 회의 중 · 15:00에 끝나요" / "지금 외근 · 고객사 중 · 17:00까지" / "오늘 연차로 자리에 없습니다. 급한 일은 메시지를 남겨 주세요".
- **비어 있는 시간**(9~18시, 점심 12~13시 제외, 30분 이상, 오늘이면 지금 이후): 버튼으로. 누르면 그 시간이 채워진 회의 일정 창(4-3, 참석자에 그 사람).
- 업무·회의 일정에 마우스를 올리면 `이 일정 묻기` → 메신저 1:1 대화를 열고 그 일정(날짜·제목)을 붙인 글을 미리 채운다.
- 바닥: `‹` `›` … `한 주 보기` `회의 잡기` `메시지`(파란 강조).
- 종일 휴가·종일 외근 날은 빈 시간 영역을 숨긴다.

### 4-3. 일정 창(지금 `WorkPlanEventModal` 고도화)

지금 구조를 유지한다: 위 머리(새 일정 · 이름 · 날짜 · 주차) / 종류 막대 / 왼쪽 입력 / 오른쪽 세로 시간표 / 바닥 버튼. 폭 약 820px.

- **종류 막대**: `업무 ▾ | 회의 | 외근 | 출장`. 각 버튼 앞에 표와 같은 색 선. 업무가 맨 앞. **태그는 `업무 ▾`를 다시 누르면 뜨는 작은 메뉴**(색 점 + 이름 + 고른 것 ✓)에서 고르고, 고르면 버튼이 `● A 프로젝트 ▾`로 바뀐다. 태그 칩 줄은 두지 않는다. 지금의 '기타' 버튼은 이 메뉴 안의 한 항목으로 들어간다.
- 오른쪽 끝: 업무일 때만 `반복 [반복 안 함 / 평일마다 / 매주 ○요일 / 매월 ○일]`(지금 '루틴'의 자리). 쓰지 못하는 '리마인드' 버튼은 뺀다.
- **제목**: 큰 밑줄 입력. 업무일 때 아래에 `최근` 내가 적은 업무 제목 5개 — 누르면 채워진다.
- **참석자(회의) / 동행자(외근·출장)**: 칩 + 검색. 검색 결과 옆에 부서와, 고른 시간에 바쁘면 "이 시간 바쁨".
- **날짜·시간**: 날짜 선택, 시작 → 끝, 길이 글자, `시간 미정`(업무) / `종일`(회의·외근·출장). 길이 버튼 30분·1시간·1.5시간·2시간·3시간. 외근·출장은 시작일 ~ 종료일, 기본 종일.
- **새 일정 시작 시각 기본값**: 09:00 고정 대신 그날 **처음 비는 시간**(점심 제외, 오늘이면 지금 이후 30분 단위). 회의는 참석자까지 모두 비는 시간.
- **장소(회의)**: `직접 적기 | 회의실`. 회의실은 지금 `RoomPicker`의 목록·승인 흐름을 그대로 쓰되, 고른 시간에 이미 잡힌 방은 "사용 중"으로 흐리게.
- **외근지·출장지**: 입력 + `최근` 행선지 버튼 + 교통수단 칩(지금과 같음).
- **메모**: 회의는 "안건 · 미리 볼 자료".
- **안내 상자**: 내 일정과 겹치면 주황 "내 일정 「코드 리뷰」(09:30)와 시간이 겹쳐요. 그래도 저장할 수 있어요." 회의에서 참석자가 바쁘면 주황 "정우성 님이 이 시간에 다른 일정이 있어요…", 모두 비면 초록 "참석자 모두 이 시간에 비어 있어요".
- **팀원 화면 미리보기**: 왼쪽 맨 아래 점선 위에 "팀원 화면에는 이렇게 보여요" + 표에 나올 한 줄(C 모양)이 입력에 따라 바뀐다.
- **오른쪽 시간표**(8~20시): 내 그날 다른 일정 회색, 점심 빗금, 오늘이면 지금 시각 빨간 선, 이 일정 파랑(겹치면 주황). 회의면 참석자 바쁜 시간이 보라 반투명으로 겹쳐 보이고, 아래에 `참석자 모두 가능한 시간` 버튼(최대 4개). 빈 곳을 누르면 그 시각(30분 단위)으로 옮겨진다. 위 `‹ 날짜 ›`로 날짜 이동.
- **바닥**: 새 일정이면 왼쪽 `☐ 저장하고 이어서 적기`, 수정이면 왼쪽 `삭제`(지우면 되돌리기 알림). 오른쪽 `Ctrl+Enter 저장` 안내, `취소`, `저장`(참석자가 있는 새 회의면 `저장하고 초대 보내기`).
- 보기 전용(남의 일정 열기) 동작은 지금과 같다(참석 취소·참석자로 합류 등).

### 4-4. 시안에 있지만 이번에 넣지 않는 것

- 온라인(화상) 회의 주소 만들기 — 연결할 서비스가 없다. 장소 버튼에서 `온라인`은 빼고 `직접 적기 | 회의실`만 둔다.

### 4-5. 사람 순서와 부서 관리

**지금**: 업무계획 "정렬 순서" 창에서 관리자가 정한 전 직원 순서(`displayOrder`)가 맨 앞 기준이고, 그다음 임원 → 부서(조직도 순서) → 직책 → 직급 → 이름(`src/domain/user/rosterOrder.ts`). 이 기준은 근태·식권·모바일 관리 화면도 같이 쓴다. 부서 관리(`DepartmentScreen`)에서는 부서 순서를 바꿀 수 없다("배치 순서에 따라 시스템 자동 관리", 새 부서는 맨 끝).

**바꾼 뒤**
- 업무계획의 `↕ 정렬 순서` 버튼·`RosterOrderModal`과 수동 순서(`displayOrder`)를 없앤다. 같은 기준을 쓰는 근태·식권·모바일 화면도 수동 순서 없이 같은 규칙으로 정렬된다.
- 부서 묶음 순서 = **부서 관리에서 정한 순서**(`departments.order`). 맨 위에는 **내 부서**를 올린다.
- 부서 안 사람 순서 = 직책 → 직급 → 이름(자동, 손으로 바꾸지 않는다).
- **부서 관리에 순서 바꾸기를 추가**: 부서 목록에서 같은 상위 부서 안의 형제끼리 `▲ ▼`(또는 끌어 옮기기)로 순서를 바꾸고 저장한다. 바꾼 순서는 조직도·업무계획·근태 등 부서를 줄 세우는 모든 화면에 반영된다. "시스템 자동 관리" 안내 문구는 지운다.
- 임원: 별도 묶음 **"임원"**을 부서들보다 위에 두고 기본으로 펼친다(임원끼리 직급 → 직책 → 이름).
- 겸직자: 지금처럼 본직 부서와 겸직 부서 양쪽 묶음에 모두 나온다.

## 5. 지켜야 할 것

- 결재 문서(`approvalDocs`)·서식(`approvalForms`) 데이터는 건드리지 않는다.
- 운영 DB의 `rosterOrder` 설정(수동 순서) 문서는 지우지 않고 **읽지 않게만** 한다(되돌릴 수 있게).
- 부서 순서 값은 기존 `departments.order`를 그대로 쓴다(새 칸을 만들지 않는다).
- 화면에 개발용 ID·"~에 저장되어 표시" 같은 안내문을 넣지 않는다.
- 업무계획 보기 권한(전사 통일)은 바꾸지 않는다.

## 6. 정한 것 / 만드는 사람이 정할 것

**사용자가 정한 것**: ② 팀 업무 채택, C 모양, 부서 줄에 오늘 업무 건수 없음, 사원 구분 강화와 가로줄 강조·이름 안내, 세로 열 강조 없음, 칸 클릭 = 그날 상세, 칸 옆 작은 창(모달 아님), 스크롤해도 유지, 내/남 일정 다른 동작, 지금 일정 창 고도화, 태그는 메뉴로, 수동 정렬 제거와 부서 관리 수정.

**설계자가 정한 것(확인 부탁)**
- 수동 정렬 제거가 근태·식권·모바일 화면에도 같이 적용된다.
- 임원은 맨 위 "임원" 묶음.
- 시안 수치(3줄, 54px 주말 칸, 360px 상세 창, 820px 일정 창, 4초 되돌리기, 8~20시 시간표)는 그대로 시작값.

- "이 일정 묻기"·"메시지"는 기존 메신저 1:1 대화로 연결(새 기능 아님).
- "최근 적은 업무"는 내 업무계획 항목 제목 중 최근 것 5개(같은 제목은 하나로).

# 기업 신규 등록 창 — 단계 표시 개편 (설계)

2026-11-16 · 사업관리 › 기업 정보 · 대상 파일 `src/modules/biz/company/CompanyFormModal.tsx`

## 왜
담당자가 처음 기업을 등록할 때 무엇부터 입력하는지, 지금 어디까지 했는지, 입력한 것이 어떻게 저장되는지를
한눈에 보이게 한다. 지금은 900px 창에 칸이 나열돼 있어 순서·필수 여부·진행 상황이 보이지 않는다.

## 목표 / 하지 않을 것
- 목표: 한 화면 안에서 입력 순서를 **왼쪽 세로 단계선**(번호 + 연결선)으로 보여 주고, 단계마다 상태를 표시한다.
- 하지 않음: 저장 방식·데이터 구조·검증 규칙 변경(저장소·훅·`schema.ts` 그대로), 상세 창 개편, 주소 검색(외부 스크립트 필요 — 따로 결정).
- 실패로 볼 것: 단계를 넘기는 클릭이 생기는 것(마법사 방식), 수정할 때 칸이 숨어 있는 것, 화면에 설명 안내문·내부 코드가 보이는 것.

## 고려한 방법
1. **왼쪽 세로 단계선 — 선택(사용자)**. 칸과 단계 번호가 같은 줄에 붙어 순서가 가장 직관적이고, 등록·수정이 같은 창.
2. 위쪽 진행 막대 + 아래 전체 펼침 — 막대와 칸이 떨어져 '이 칸이 몇 단계인지'가 덜 보임.
3. 접히는 단계(아코디언) — 깔끔하지만 수정·되돌아가기에 펼치는 클릭이 늘어남. 장점(한 줄 요약)만 1안에 가져온다.

## 정한 것
**단계와 순서** (모두 한 화면에 펼쳐짐)
1. 기본 정보 — 기업명·사업자등록번호(필수), 대표자·대표번호
2. 주소 — 도로명 주소·상세 주소 (선택)
3. 계좌 — 여러 개, 기본 계좌 하나 (선택)
4. 메모 (선택) — 지금은 계좌 앞에 있는 것을 맨 뒤로

**단계 표시** (왼쪽 동그라미 + 세로 연결선, 단계 제목 오른쪽에 상태)
- 필수 단계: 빈 상태 ○ 회색 → 입력 중 ◐ 청록 테두리 → 완료 ✓ 청록 채움 → 문제 있음 ! 빨강(중복 번호 등)
- 선택 단계: 비어 있으면 '선택' 회색 글씨, 입력하면 ✓
- 완료한 단계 제목 옆에 **한 줄 요약**(제 판단): 예) `대성반도체(주) · 123-45-67890`, `서울 강남구 테헤란로 …`, `계좌 2개 · 기본 신한 110-…`
- 연결선은 완료된 단계까지 청록, 그 뒤는 회색

**칸 다듬기** (제 판단)
- 오류는 칸 바로 아래에 표시(칸을 벗어날 때부터). 저장 시 맨 아래 묶음 목록은 서버 오류 등 칸에 붙일 수 없는 것만.
- 계좌는 7칸 표 대신 **계좌마다 카드 한 줄**: 은행 · 계좌번호 · 예금주, 오른쪽에 '기본' 칩(누르면 기본으로)과 빼기. 메모는 카드 안 작은 칸. 저장된 계좌를 빼면 지우지 않고 흐리게 '사용 안 함' + 되살리기.
- 신규 등록에서는 '사용 여부'를 숨김(항상 사용). 수정일 때만 창 아래 왼쪽에 사용/사용 안 함 전환.
- 창 아래(저장 단추 왼쪽)에 `필수 2/2` 진행 표시. 저장 단추는 늘 누를 수 있고, 누르면 문제 있는 첫 칸으로 이동.
- 창 폭 900 → 760 정도(한 열 흐름이라 좁혀도 됨).
- 화면 문구는 설명 안내문 없이 칸 이름·예시(placeholder)만.

## 만드는 사람 몫
색·간격·아이콘 세부, 단계 상태 계산을 순수 함수로 빼서 테스트하는 방식, 카드 반응형(좁은 화면에서 줄바꿈).

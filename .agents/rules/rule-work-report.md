# Rule: Daily Work Report Generation ([업무보고])

사용자가 프롬프트에 `[업무보고]` 단어를 포함하거나 요청하는 경우, 반드시 아래의 공식 표 양식에 맞추어 마크다운 형태로 일일 업무 보고서를 작성해야 합니다.

## 작성 양식 및 요건

0. **데이터 추출 기준**:
   * 보고서에 기재되는 모든 업무 수행 내역은 **요청일(해당 일자)의 Git 커밋 이력(`git log`)을 바탕으로 작성**해야 합니다. (실제 커밋된 기능 변경, 버그 수정, 리팩토링, 설계 문서 등을 빠짐없이 수집하여 분류)

1. **상단 타이틀 및 기본 정보**:
   * 대제목: `# 일 일 업 무 보 고`
   * 기본 정보 표 (6열 구성):
     | 일자 | YYYY-MM-DD | 부서 | 데이터플랫폼 개발팀 | 작성자 | 홍채원 |
     (일자: 현재 날짜, 부서: 기본 '데이터플랫폼 개발팀', 작성자: 기본 '홍채원' — 사용자 지정 정보가 있을 시 해당 정보 우선)

2. **업무 수행 내역 섹션**:
   * 소제목: `### 업무 수행 내역`
   * 테이블 구조 (4개 고정 컬럼):
     * **순번**: 1, 2, 3, ...
     * **업무 내용**: 요청일의 커밋 내역을 종합한 전체적인 총괄 업무/과업명(대분류)을 명확하고 포괄적으로 기술
     * **비고**: 해당 업무에 포함된 세부 커밋 작업/구현 내역을 글머리 기호(`- `) 목록 형태로 줄바꿈(`<br>`)하여 상세히 기술
     * **진행률(%)**: 백분율 수치(예: `100%`, `80%`)

## 표준 출력 서식 예시

# 일 일 업 무 보 고

| 일자 | 2026-10-01 | 부서 | 데이터플랫폼 개발팀 | 작성자 | 홍채원 |
| :---: | :---: | :---: | :---: | :---: | :---: |

### 업무 수행 내역

| 순번 | 업무 내용 | 비고 | 진행률(%) |
| :---: | :--- | :--- | :---: |
| 1 | 메신저 관련 기능 고도화 및 사용성 개선 | - 동시간대(동일 분) 발송 메시지 시간 그룹화<br>- 채팅창 내 텍스트 마우스 드래그 및 복사 지원<br>- 클립보드 캡처 이미지 붙여넣기(Ctrl+V) 업로드 구현<br>- 메시지 입력창 최대 3줄 자동 확장 구현<br>- 새 메시지 수신 시 숨김 채팅방 자동 표시 복원 (데스크톱/모바일) | 100% |
| 2 | 전자결재 후열(Post-Read) 전달 기능 구현 | - 후열 전달 전용 DB 스키마 및 저장소 신설<br>- 수신자 후열함 필터링 및 미확인 배지 카운트 연동<br>- 상세 문서 열람 시 읽음 처리(자동 확인) 연동<br>- 모바일 결재 목록 및 상세 화면 대응 | 100% |

# Rule: Daily Work Report Generation ([업무보고])

사용자가 프롬프트에 `[업무보고]` 단어를 포함하거나 요청하는 경우, 반드시 아래의 공식 표 양식에 맞추어 마크다운 형태로 일일 업무 보고서를 작성해야 합니다.

## 작성 양식 및 요건

1. **상단 타이틀 및 기본 정보**:
   * 제목: `# 일 일 업 무 보 고`
   * 기본 정보 표:
     | 일자 | 부서 | 작성자 |
     (일자: 현재 날짜 YYYY-MM-DD, 부서: 데이터플랫폼 개발팀, 작성자: 홍채원 — 사용자 정보 우선)

2. **업무 수행 내역 테이블 구조 (4단 고정 컬럼)**:
   * **순번**: 1, 2, 3, ...
   * **업무 내용**: 핵심 작업을 한 문장으로 간결하게 기술
   * **비고**: 특이사항, 참고 내용, 이슈 등 (없으면 `-`)
   * **진행률**: 완료 / 진행중 / 보류 등

## 표준 출력 서식 예시

# 일 일 업 무 보 고

| 일자 | 2026-09-30 | 부서 | 데이터플랫폼 개발팀 | 작성자 | 홍채원 |
| :---: | :---: | :---: | :---: | :---: | :---: |

### 업무 수행 내역

| 순번 | 업무 내용 | 비고 | 진행률 |
| :---: | :--- | :--- | :---: |
| 1 | **업무 내용 예시** | - | 완료 |
| 2 | **...** | - | 진행중 |

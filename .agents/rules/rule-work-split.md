## 3. 커밋·브랜치 규칙
- `git add`는 **본인이 수정한 파일만 경로로 지정**합니다 (`git add .` / `git add -A` 금지 — 상대의 미완성 작업이 섞임).
- 커밋 전 `npx tsc --noEmit`, 관련 테스트, 가능하면 `npm run build`로 검증합니다.
- 테스트는 vitest가 아니라 **node:test**: `npx tsx --test <파일>`
- `main` push(=운영 배포)는 사용자 승인 후, [rule-git-sync.md](rule-git-sync.md) 절차를 따릅니다.
